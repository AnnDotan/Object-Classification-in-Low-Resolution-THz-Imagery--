## 8 gotchas the new box should know about
Captured in detail in [docs/runbooks/PHASE_B_EXECUTION.md](docs/runbooks/PHASE_B_EXECUTION.md) → **Known issues / gotchas**. Highlights:
1. `make_venv` doesn't pick Py 3.12 — bootstrap manually if no 3.11/3.10
2. `--min-vram-gib 6.0` strict-fails on 6 GiB cards — use 5.9 or upgrade GPU (RTX 5070 12 GB clears this comfortably)
3. `requirements.txt` is UTF-16 LE (preserved per migration spec); `requirements.lock.txt` is UTF-8 (canonical for `setup_gpu_env.py`)
4. `find_running_transnext_processes` false-positives on VSCode Pylance — `nvidia-smi` is the substantive check
5. PS 5.1 `*>>` redirect breaks logs — use `cmd /c "... 2>&1 >> log"`
6. New `scripts/*.py` need `sys.path.insert(0, REPO_ROOT)` if they `import src.*`
7. Bash background tasks are capped at 10 min — use `Start-Process` for multi-hour jobs
8. `optuna.optimize(n_trials=20)` ADDS 20 trials, doesn't ensure 20 total — `run_tune_chain.ps1` already guards this

Everything you need to pick this up cold on the new computer is in the four updated docs (PRD, runbook, README, this file) + progress.txt. Ready when you are.
