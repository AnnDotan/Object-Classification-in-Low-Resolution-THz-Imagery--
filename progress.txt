## Learnings (resume session)
- gitignore's "can't re-include children of an excluded dir" rule trips up the natural pattern of `artifacts/` + `!artifacts/priors/`. Resolution: enumerate the excluded sibling subpaths instead of blanket-blocking the parent. Tracked-by-default + explicit-exclusion-list scales better as new artifacts subdirs appear.
- Lightning callbacks can detect WandbLogger by class-name match without importing pytorch_lightning.loggers.WandbLogger — keeps the callback dep-light and survives offline-mode init failures (which raise on .experiment access).
- The 186-cell matrix dispatch order (A->B->C, model-dataset innermost) is load-bearing: the dashboard, Final_Exp.md, and all "skip-existing" checks rely on it. Tests pin it explicitly via `actual_tags == [c.tag for c in build_final_matrix()]`.
- `tempfile.TemporaryDirectory(ignore_cleanup_errors=True)` is required on Windows whenever a test opens SQLite (Optuna) files inside the temp dir — Windows holds file locks past Python's cleanup window.
- Auto-download URL guessing for pretrained weights is fragile; the safest pattern is "try a default, fall back to env-var override, fall back to a clear FileNotFoundError with manual instructions." The TransNeXt helper (src/models/transnext_weights.py) follows this — never silently trains on random init when pretrained=True.

## Learnings
- Saturation lerp was already implemented end-to-end in degrade.py before US-001 started; the only gap was the DataConfig override (legacy/ad-hoc path) and the test coverage. degrade_config_for() and degrade_image() already handled it correctly.
- Project venv lives at `venv/` (NOT `.venv/`). `.venv/` exists but lacks torch. All test invocations must use `venv/Scripts/python.exe`.
- The pipeline never converts grayscale_lerp(s=1.0) on the fast path — there's an explicit `if s < 1.0` guard in degrade.py:98, which is what makes the saturation=1.0 no-op test pass byte-exactly.
- scikit-image is NOT installed in the venv; use torchmetrics.image.{PeakSignalNoiseRatio, StructuralSimilarityIndexMeasure} instead. data_range=1.0 since all tensors are clipped to [0,1].
- Phase B L3 cifar10 SSIM ~0.05 is not a bug — combined heavy degradation (low_res=10, blur σ=1.3, noise std=0.09, S&P 0.08, saturation 0.5) destroys most structural similarity. PSNR ~14 dB is consistent.
