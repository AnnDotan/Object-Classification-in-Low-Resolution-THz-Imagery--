## Learnings
- The project does not use pytest, mypy, or any conftest.py — tests follow a stdlib + tempfile pattern with `def main(): ...; sys.exit(main())`.
- run_status.detect_status emits "Complete", not the PRD's "Done". Schema matches the on-disk producer; renderer maps both for display.
- Torch-free path matters: src.experiments.cells.iter_cells() is the canonical enumerator for analysis tools (dashboards, tracker updaters, CI lint). matrix.build_final_matrix() additionally builds DegradeConfig per cell, which pulls in torch and breaks any tool that doesn't need pixel-level config. Use cells.iter_cells() unless you specifically need DegradeConfig.
